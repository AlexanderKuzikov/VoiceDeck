# VoiceDeck — TASK (диспетчер задачных сессий)

> Правит только штаб. Сессии этот файл не трогают.

## Как работать (постоянная часть)

1. Порядок чтения сессии: AGENTS.md проекта → контекст проекта → свой файл задачи.
2. Сессия правит только свой файл: статус, отчёт. Диспетчер, очередь, архив, журнал — штаб.
3. Жизненный цикл: открыта → в работе → на проверке → принята.
4. Отчёт в файле задачи: сделано → команды с выводами (факты) → изменённые файлы → хвосты и вопросы штабу. Без выводов команд не принимается.
5. Сессия сама коммитит и пушит свой номер (коротко, без точек). Чужие файлы не трогать.
6. Одно задание — одна работа. EN-юнит и DE-пак — всегда разные номера.
7. Запуск сессии фразой: «VoiceDeck. Читай docs/TASK.md». Возврат: «читай файл задачи, там отчёт».
8. Заморозка объёма: новое по ходу — отдельным номером, не абзацем в отчёт.

## Приёмка контентных задач (юниты)

- Папка `library/<lang>/<date>-<slug>/` содержит: meta.json, заявленные txt, audio/*.mp3, anki.tsv.
- Каждый mp3 открывается (размер > 5 КБ). Строк в anki.tsv = числу фраз.
- meta.json валиден, поля как в шаблонах библиотеки.
