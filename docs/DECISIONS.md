# VoiceDeck — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-09-16: Движок — Microsoft Neural через edge-tts, облако

**Контекст:** Нужна озвучка небольших текстов EN/DE уровня «живой голос, никаких роботов». Локальные движки отпали по качеству, Google AI Studio — по глюкам доступа из РФ, ElevenLabs — официально блочит Россию.

**Решение:** База — Microsoft Neural через бесплатный endpoint (либа edge-tts). Своё железо не участвует, VPN и ключи не нужны.

**Альтернативы:** ElevenLabs v3 (эталон выразительности, но бан РФ + VPN + иностранная карта); Gemini TTS (топ-качество, но suspicious-activity баны); Yandex SpeechKit (по одному голосу на EN/DE — мало); Piper/RHVoice локально (роботизированность).

**Trade-off:** Нет студийного HD-качества и эмоций уровня Eleven; неофициальное API без SLA — Microsoft может поменять endpoint.

## 2026-09-16: Приложение — один CLI-файл, Anki через TSV, склейки через ffmpeg

**Контекст:** Нужны чтение, listening, shadowing и карточки фраз с озвучкой в одном инструменте без зоопарка зависимостей.

**Решение:** `scripts/voicedeck.py` — один файл на argparse+asyncio (зависимость только edge-tts). Четыре команды: say (фраза → normal/slow/srt/shadow-микс), batch (пачка → mp3 + anki.tsv + manifest), dialog (реплики разными голосами → mix.mp3 + playlist.m3u + anki.tsv), cards (TSV фраза-перевод → озвучка обеих сторон). Пресеты голосов зашиты в код. Проверки — команда selfcheck без сети вместо тестового фреймворка.

**Альтернативы:** Разбивка на пакет из модулей; SQLite вместо файлов; склейка наивной конкатенацией mp3 без ffmpeg; Anki Connect API вместо TSV.

**Trade-off:** Один файл разрастётся при добавлении GUI/веба — тогда делить; TSV-импорт в Anki ручной (зато без плагинов и сервера).

## 2026-09-16: Интерфейс — локальный веб на stdlib, в стиле базы знаний

**Контекст:** Учиться командами из терминала неудобно, нужен нормальный интерфейс прямо сейчас, без новых зависимостей и сборок.

**Решение:** `scripts/app.py` на ThreadingHTTPServer (только stdlib) + одна vanilla-страница без CDN, в токенах из базы знаний (светлая/тёмная темы). Бэкенд переиспользует функции CLI. Тренажёр карточек с прогрессом — в браузере (localStorage), сервер только озвучивает и пакует ZIP. Запуск в один клик через VoiceDeck.bat.

**Альтернативы:** Go+WebView (настоящее окно, но нужен Go-тулчейн и сборка — апгрейд на потом); tkinter (сразу окно, но бедный UX); Electron/фреймворки (тяжело, против zero-dependency).

**Trade-off:** Вкладка браузера вместо окна приложения; офлайн-персистентность прогресса только в этом браузере.

## 2026-09-16: Библиотека юнитов — продукт, аудио коммитится

**Контекст:** Материалы должны копиться в переиспользуемую систему: повторение себе + пригодность новым учащимся. Разовые файлы в out/ для этого не годятся.

**Решение:** Юнит дня `library/<lang>/<date>-<slug>/`: meta.json (уровень, тема, трек, голоса, спираль), story/dialog/phrases/cards как txt с `#`-комментариями, `audio/` коммитится (файлы мелкие, это продукт), anki.tsv рядом. DE первые 2 недели — юниты без story, только phrases. Следующий шаг — команда build для сборки юнита одной командой.

**Альтернативы:** Всё в out/ без структуры (теряется повторное использование); SQLite-каталог (тяжело, нечитаемо); аудио только локально без коммита (новым учащимся достаётся немая библиотека).

**Trade-off:** Репозиторий пухнет на мегабайты аудио — приемлемо для учебных объёмов; при росте — LFS или релизные ZIP.
