# Задача 0004 — Словарь DE-A1 (Wortliste Гёте + фразы)

> Проект: VoiceDeck. Статус: принята. Дата: 2026-10-11.

## Задание

Собрать `library/vocab/de-a1.tsv`: официальный Wortliste Goethe-Zertifikat A1
(Start Deutsch 1, ~650 главных статей + подстатьи + Wortgruppen) + к каждому:
часть речи, русский перевод, учебная фраза A1 с переводом. 7 батчей
(A–C, D–G, H–M, N–S, T–Z, Zahlen/Uhrzeit, Restgruppen), сборка и приёмка — на штабе.
Сырьё: официальный PDF скачан в песочницу, статьи извлечены штабом в тексты батчей.

Входит:
- поиск официального PDF, извлечение списка, перевод + фразы, сборка, приёмка

Не входит: A2+, озвучка, матрица покрытия.

Старт: формат — AGENTS.md проекта (раздел vocab); итог задачи 0003 как образец.

Приёмка:
- число строк = числу слов Wortliste; везде 5 колонок, pos из набора, пустых клеток нет
- выборочно: фраза содержит слово, перевод естественный

Ограничения: только после приёмки 0003; коммит+пуш своего номера; чужие файлы не трогать.

## Порядок работы

Прочитай AGENTS.md и контекст → сделай → проверь по приёмке → допиши отчёт ниже → статус «на проверке», жди.

## Отчёт сессии

Батчи 1–7 выполнены сабагентами штаба (143+154+141+133+106+62+63 = 802 строки).
Приёмка штаба: счёт батчей сошёлся; сильные глаголы — формы верны (ложные срабатывания
проверки); sie/Sie — разные строки осознанно; 5 дублей двойной вставки штаба убрано
при слиянии (an/auf sein, Datum, Stunde, Grad).
Итог: library/vocab/de-a1.tsv (шапка-атрибуция + 797). Статус: принята.
