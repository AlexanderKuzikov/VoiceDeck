# Задача 0003 — Словарь EN-A1 (552 слова с фразами)

> Проект: VoiceDeck. Статус: принята. Дата: 2026-10-11.

## Задание

Собрать `library/vocab/en-a1.tsv`: первые 500 лемм NGSL 1.2 (ранги 1–500) + 52 supplementary
(дни/месяцы/числа). К каждому слову: часть речи, русский перевод, учебная фраза-чанк A1
с русским переводом. Работа идёт 6 батчами (ранги 1–100 … 401–500 + supplementary),
сборка и приёмка — на штабе.

Входит:
- перевод + pos + фраза на каждое слово; шапка-атрибуция NGSL (CC BY-SA 4.0)
- слияние батчей в один файл, проверка приёмки

Не входит: A2+, немецкий трек, озвучка (отдельные задачи), матрица покрытия.

Старт: формат — AGENTS.md проекта (раздел vocab); сырьё — `C:\Users\alexa\AppData\Local\Temp\opencode\vocab\en-a*.txt`.

Формат строки: `word<TAB>pos<TAB>ru<TAB>phrase<TAB>phrase_ru`, pos ∈ verb|noun|adj|adv|func|num.
Фраза: чанк со словом (любая форма), ≤8 слов, present simple, конкретика. Пример:
`buy<TAB>verb<TAB>покупать<TAB>I buy bread every morning<TAB>Я покупаю хлеб каждое утро`

Приёмка:
- 552 строки данных + шапка; везде ровно 5 колонок, pos из набора, пустых клеток нет
- выборочно: фраза содержит слово, перевод естественный

Ограничения: батчи пишут только свои slice-файлы во временную папку; финальный файл собирает штаб.

## Порядок работы

Прочитай AGENTS.md и контекст → сделай батч → проверь по приёмке → допиши отчёт ниже → статус «на проверке», жди.
